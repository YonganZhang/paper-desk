# 语气、疑难情形与改稿写作

写回复、处理不采纳和疑难意见、改正文措辞时读本页。团队有自己的写作规范时，以团队规范为准。

## 1. 基本姿态

- 合作但不卑微；以证据说话，不以态度说话。
- 简洁，让编辑能快速核对；尊重审稿人，但不隐瞒研究的边界。
- 缺信息、没解决的风险如实标出，不包装成已解决。

可用句式（事实支持时才用）：

```text
We agree that the original wording did not make this point sufficiently clear.
We have revised the manuscript to clarify ...
To address this concern, we performed ... The new analysis shows ...
We have therefore softened the claim from ... to ...
We respectfully disagree with this interpretation because ...
We now explicitly acknowledge this limitation in the Discussion.
```

不能当最终回复的写法：

```text
The reviewer misunderstood ... / The reviewer is wrong ...
Due to lack of funding/time, we cannot ...
We believe this is sufficient.
We have revised accordingly.          （没说改了什么、改在哪）
Thank you for the comment.            （致谢不能代替回答）
```

## 2. 不同意时

顺序：承认关切 → 把分歧收窄到具体一点 → 给出稿件证据、外部证据或研究范围的理由 → 稿件可能引起误解的地方做小幅澄清 → 不把分歧个人化。

```text
We appreciate the reviewer raising this issue. We respectfully disagree that [narrow point], because
[evidence or scope reason]. To make this clearer, we have revised [location] to state that [revised text].
```

审稿人看漏或误解时，不说对方误解，当作稿件表达问题处理："We agree that the original text did not make this distinction sufficiently clear. We have revised [section] to clarify that …"

## 3. 疑难情形

| 情形 | 做法 |
|---|---|
| 做不到的实验（需要新数据集、长期观测、新平台或不同研究设计） | 肯定其科学价值 → 说明研究设计或范围的边界 → 有替代证据就给 → 收窄结论或补 Limitations。不以时间、经费、能力为主要理由 |
| 审稿人事实性错误 | 不指责；指出稿件里已有数据的位置；稿件表达不清就改；即使审稿人错了也考虑做一处小改 |
| 审稿人之间要求冲突 | 先在对照表里标出冲突；有编辑明确指示时优先；找同时满足双方关切的最小改动；不作互相矛盾的承诺；必要时在两条回复里说明取舍 |
| 审稿人要求引用特定文献 | 评估相关性；只加真正相关且已核实的；措辞中性；元数据缺失时标"待作者提供"。不相关的可以礼貌说明未加的理由 |
| 重大统计质疑 | 按高风险处理：向作者要检验名称、样本单位、样本量、效应量或置信区间、多重比较校正、软件版本，以及方法与结果的位置。不编统计结果 |
| 伦理、合规、数据完整性质疑 | 作者给出确切事实（审批机构与编号、知情同意、数据/图像处理说明、利益冲突更正）前不能交付；不绕开缺失的合规信息写回复 |
| 带审稿意见转投 | 确认新期刊是否要求回复原审稿意见；尽量保留原审稿人编号；按新期刊格式调整 |
| 拒稿后想申诉 | 申诉不是返修，单独处理：按期刊的申诉规则写，不套本技能的回复信流程 |

## 4. 主张强度

强证据用 demonstrate / show / establish；中等用 indicate / suggest / support；关联性或有限证据用 are consistent with / may reflect / raise the possibility。审稿人质疑因果而证据是关联性的，先把正文里的因果动词改弱，再写回复。

## 5. 改正文时的写作底线

1. 一段一条主线：新增内容要接进所在段落的主线，不是在段尾追加一句孤立的解释。
2. 一句一个论证中心：为回应意见补的限定、定义和条件，过长时拆句。
3. 信息增量决定篇幅：不为显得"改得多"而加空话。
4. 承接表达真实关系：改了前文，后面承接它的句子一起改。
5. 正文不写修改痕迹：不在正文里写 "as suggested by the reviewer" 或旧版本为什么错；正文只写当前的结果和解释，修改说明放回复信。
6. 边界集中写：局限放 Discussion 或 Limitations 一处，不在每句话里加免责。
