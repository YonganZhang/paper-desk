新手教程

三分钟看完。这个系统只做一件事：把「哪篇论文、谁写的、投到哪、什么时候投的、用哪个账号投的」记清楚。

它是干什么用的

  • 论文投出去之后，在这里登记一条记录。
  • 被拒了要转投别家，不用删旧记录——直接加一条新的，旧的自动变成投稿历史，以后随时能查「这篇之前投过哪些期刊」。
  • 投稿系统的账号密码记在这里，换人接手、老师帮忙查稿件时不用到处问。
  • 投稿包（Word / PDF / LaTeX 压缩包）传上来，稿件不会散在各自电脑里。

❗ 审到第几轮、编辑说了什么这类细节不用记。只记「投到哪、什么时候、现在大概什么状态」就够了。

怎么用（学生）

  1. 注册一个自己的账号 在登录页点「自己注册一个」，填账号（英文）、姓名（中文）、密码；要求邀请码时向老师（管理员）要。不用审批，注册完直接能用。 你只能看到自己录入的论文；老师（管理员）能看到全部。
  2. 新建论文 首页点「+ 新建论文」。必填只有英文标题。 作者顺序请一行写一个作者，从第一作者往下排，这样顺序不会记乱。
  3. 填投稿信息 期刊名、投稿系统网址、投稿系统账号密码、投稿日期、稿号。 不知道账号密码？先看顶栏的「公共投稿账号」，课题组通用的投稿邮箱都在那里。
  4. 上传投稿包 在论文详情页底部上传，Word / PDF / LaTeX 的 .zip 都行，单个文件最大 {{ max_mb }} MB。 LaTeX 项目请先打包成 .zip 再传。文件太大就只传最终 PDF + 源码包。
  5. 被拒了要转投：加一条新记录，别改旧的 论文详情页 →「+ 新增一次投稿 / 转投」。系统会自动编号成「第 2 次 / 第 3 次」，并把上一次标记为「转投」。 这样投稿历史才留得住。直接把旧记录改成新期刊，历史就丢了。
  6. 状态变了回来改一下 状态变了（被拒 / 已录用 / 撤稿），进对应那条投稿记录点「编辑」改一下。论文总状态会自动跟着最新一次走。 一分钟的事，别攒着。

怎么用（管理员）

  • 管理员账号看到的是全部人的论文，列表里有「录入人」一列，知道每篇是谁登记的。
  • 公共投稿账号页：录入课题组通用投稿邮箱和各系统账号，所有学生都能看到。
  • 花名册页：维护成员中英文名、邮箱、单位、常用角色，学生填作者时会自动提示。
  • 论文详情页可以「转移归属」——学生注册前你先替他录的论文，之后一键转给他。
  • 首页「导出 CSV」把全部台账导成 Excel 能开的表格。
  • 管理页可以改站点公告、重置学生密码、停用账号，也能查看、修改或关闭「注册邀请码」（新装默认开启）。

几条规矩

  • 投出去当天就来记一条，别等到想不起来日期。
  • 公共账号密码只在投稿系统里用，不要转发到群里、不要截图外传。
  • 删除是不可恢复的。删之前想清楚，尤其是整篇论文。
  • 系统只是台账，正式稿件请同时留好自己的本地备份。

常见问题

Q：我看不到别人的论文，是不是坏了？
A：不是，学生账号本来就只能看自己的。老师那边能看到全部。

Q：忘记密码了？
A：找管理员在管理页给你重置。

Q：一篇论文投了三家期刊，要建三条论文吗？
A：不用。一篇论文一条记录，投几次就在里面加几条投稿记录。

Q：还没投稿，只是写完了，能录进来吗？
A：能。状态选「撰写中」，投稿信息整块留空，投出去之后再补。

Q：LaTeX 包超过 {{ max_mb }} MB 怎么办？
A：把大图和中间产物剔掉再打包；实在不行只传最终 PDF，源码包放实验室服务器或网盘并在备注里写路径。
