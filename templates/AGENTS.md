# AGENTS.md — 已投稿论文项目（PaperDesk 模板）

> 用法：复制到你管理已投稿论文的项目根目录，按注释改成自己的情况。Claude Code 读 `CLAUDE.md`，可建一个软链或同名副本指向本文件。

## 一句话
追踪课题组已投稿论文：投稿、转投、审稿状态、决定信、返修和最终去向。

## 真源分工
- **论文信息只在投稿台账**（`paper` 命令；网站 `http://127.0.0.1:8611`）：状态、各轮期刊与稿号、作者、负责人、跟进方式、审稿阶段、返修截止、决定信、跟进计划。别处只放指针，不抄副本。
- 本地稿件文件（LaTeX 源、改稿稿）放 `papers/<台账编号>/`；每轮实际提交的投稿包上传到台账附件。
- 项目任务（这周要做什么）放项目计划文件，不放论文清单。

## 谁跟进（改成你们的规定）
- 「负责人」是跟进人姓名；**AI 怎么跟只看跟进方式**：`ai`=AI 代查、`self`=本人自查、`student`=学生自管、`watch`=学生改稿·AI 盯截止、`partner`=合作方自管。
- 例：本人一作的论文负责人记本人、跟进方式 `ai`；学生一作的记学生、`student`；合作方投稿、本人只是合著者的论文分类记 `partner`，不计入主序列。
- 例外：本人是投稿系统里的通讯作者或投稿人、某家期刊的旧流程没关时，提醒一次（防一稿多投）。

## 改数据的铁律
1. 转投用 `paper submit` 新增一轮；绝不改旧轮的期刊名。更早的轮次用 `paper submit --history` 补录，旧轮结局用 `--outcome`。
2. 任何批量脚本都不许先删后建；删除不可恢复，`rm`／`rm-sub`／`rm-file` 要 `--yes`，删附件前先另存。
3. 不确定就先 `paper show <编号>`；写完回读。
4. 追加备注前从库里只读取原文（CLI 输出会把凭证打码）；当前情况写 `paper edit --current`。
5. 改审稿阶段用 `paper progress`，改返修截止用 `review-add --due`；跟进计划只记卡点和下一步。

## 投稿与查稿
- 网上投稿：技能 `paper-submit`。终点动作（Approve／Submit／正式投稿）只在用户对**这一篇**明确批准后单独执行一次；投完登记台账。
- 查稿和每周报告：技能 `paper-status-check`。只读，不点改变稿件状态的按钮，不回编辑的信；状态以投稿系统列表页为准。
- 浏览器操作和例行查稿可以交给便宜模型；判断、审阅、终点动作前的核对由主模型或人来做（见 `skills/paper-submit/references/agents-and-models.md`）。

## 边界
- 投稿系统账号密码只用 secret 名或取密码命令，真值不进命令行、日志、回复和仓库。
- 台账数据库含明文投稿密码：不外发、不进 Git；只在本机和备份里。
- 打电话、写信给编辑部、付费、版权声明、作者本人才能做的确认，交给人。
